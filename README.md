# 🤝 VoluntárioHub — Projeto Integrador

O **VoluntárioHub** é uma plataforma web desenvolvida para conectar voluntários a ONGs e causas sociais. O sistema permite o gerenciamento de vagas de voluntariado, exibição de depoimentos e acompanhamento de impacto social.

---

##  Tecnologias Utilizadas

* **Back-end:** Python, Django
* **Banco de Dados:** MySQL
* **Front-end:** HTML5, CSS3, JavaScript, Bootstrap 5
* **Controle de Versão:** Git & GitHub
